# Remind rules

Read [CLAUDE.md](../../../CLAUDE.md) in full, now, from the file — not from
memory of it earlier in this session.

Then, before the next reply:

1. **Name the sections that govern the task in hand.** Editing a test brings in
   → Verifying changes → What a test is for; touching a play mode brings in →
   Architecture; anything writing a sentence anywhere brings in → Writing style.
   Say which ones, so the choice is visible and can be corrected.
2. **→ Talking to me applies to every reply**, whatever the task. A proposal
   that arrives without its four parts, or that describes an edit instead of
   quoting the resulting text, is not a proposal.
3. **→ Writing style applies to every sentence written**, in the reply and in
   anything the task writes: `*.md`, a code comment, a skill, a commit message.

The sections are the rules; this file only says to read them. Anything restated
here is a second copy that drifts — CLAUDE.md → Documentation, "One source of
truth".
