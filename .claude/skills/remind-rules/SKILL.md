# Remind rules

Read [CLAUDE.md](../../../CLAUDE.md) in full, now, from the file — not from
memory of it earlier in this session.

Then, before the next reply:

1. **Name the sections that govern the task in hand**, so the choice is visible
   and can be corrected. Any of CLAUDE.md's sections can be the one; for
   example:

   - editing a test brings in → Verifying changes → What a test is for;
   - touching a play mode brings in → Architecture;
   - writing a sentence anywhere brings in → Writing style.

2. **→ Talking to me applies to every reply**, whatever the task.
3. **→ Writing style applies to every sentence written** — that section names
   where.

The sections are the rules; this file only says to read them. Anything restated
here is a second copy that drifts — CLAUDE.md → Documentation, "One source of
truth".
